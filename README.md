# Agenda de Contactos

Programa en Python que utiliza un **diccionario** para gestionar una agenda de contactos (nombre y número de teléfono). Desarrollado como ejercicio práctico sobre colecciones de datos (listas, conjuntos y diccionarios).

## Descripción

El programa administra una agenda de contactos a través de un menú interactivo por consola. Permite:

- **Agregar** un nuevo contacto (nombre y teléfono)
- **Mostrar** todos los contactos guardados
- **Buscar** un contacto por su nombre
- **Eliminar** un contacto de la agenda

La agenda inicia con 15 contactos de ejemplo ya cargados en el diccionario, para que se pueda probar el programa de inmediato.

## Estructura de datos utilizada

- **Diccionario (`dict`)**: cada contacto se guarda como un par `nombre: teléfono`, lo que permite buscar y modificar un contacto directamente por su nombre.

## Cómo ejecutar

```
python agenda_contactos.py
```

Luego selecciona una opción del menú (1 al 5) para agregar, mostrar, buscar, eliminar o salir.
